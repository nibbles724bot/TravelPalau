# 帛琉五天四夜自由行

適合第一次到帛琉、想體驗浮潛與島上文化的旅客。以桃園往返科羅（TPE–ROR）、四晚住科羅（Koror）、兩人同房為規劃基準。時間皆為帛琉當地時間，比台灣快一小時。先用實際日期確認去回程相隔四晚，再訂房與船團。 [中華航空航線查詢](https://flights.china-airlines.com/en-tw/flights-from-taipei-to-koror-palau)

## 每日行程

| 天數 | 上午 | 下午 | 晚上 |
| --- | --- | --- | --- |
| 第 1 天・抵達科羅 | 桃園出發，依班機時間調整 | 抵達 ROR，搭飯店接駁前往科羅，入住後在市區補水、換少量美元現金 | 科羅市區晚餐，確認隔日接送時間與浮潛裝備。晚到就直接入住 |
| 第 2 天・洛克群島浮潛 | 約 08:00–09:00 由科羅出發，搭快艇進洛克群島南潟湖。優先安排牛奶湖和一處適合初學者的淺礁 | 午餐後依潮汐安排長沙灘或第二處浮潛點，約 16:00–17:00 回科羅 | 市區晚餐，休息 |
| 第 3 天・巴伯爾道布島陸遊 | 約 09:00 包車出發，前往恩加德馬烏瀑布（Ngardmau Waterfall），預留約 2–3 小時步行、休息與折返 | 午餐後往恩吉魯穆德（Ngerulmud）看國會建築外觀，再回科羅。步道因大雨關閉時，改逛科羅博物館 | 市區晚餐，確認隔日風浪與出團狀態 |
| 第 4 天・紅樹林獨木舟與文化 | 約 09:00 參加導覽，划獨木舟探索潟湖與紅樹林。想減少體力負擔可選半日團 | 半日團結束後，參觀 Etpison Museum 的傳統舟具、錢幣與木雕。若訂到全天團，博物館移至第 1 天或第 5 天的空檔 | 整理行李，確認隔日機場接送 |
| 第 5 天・返台 | 退房，依航班寄放行李。晚班機可安排 Belau National Museum 或市區午餐 | 依航班出發，規劃起飛前約 3 小時抵達機場 | 依實際航班抵達桃園 |

出海時間為規劃用。長沙灘能否登陸取決於潮汐。獨木舟可詢問是否有半日行程、最低成團人數及救生衣尺寸。館方營業日與售票時間建議出發前確認。 [洛克群島旅客指南](https://pristineparadisepalau.com/knowledge-base/?kbai_article_slug=what-to-know-before-visiting-palaus-rock-islands) · [獨木舟業者](https://www.paddlingpalau.net/day-tours.html) · [Etpison Museum](https://www.etpisonmuseum.org/) · [Belau National Museum](https://palaunationalmuseum.pw/)

## 海況備案與門票

- **第 2 天停航**時，先與業者確認能否改到第 3 或第 4 天。第 3 天可和陸遊對調，第 4 天可用洛克群島替換獨木舟。兩天都無法出海時，安排科羅雙館、市區午餐與住宿休息。
- **想去水母湖**時，把它列為第 2 天的可選停靠點。付費前請業者確認當天開放、近期水母觀察狀況，以及是否會取代其他停靠點。
- **洛克群島許可**以成人每張 USD 50（一般）或 USD 100（含水母湖）做預算。含水母湖的許可已涵蓋其他指定觀光區。請業者確認最新費用、效期、第 4 天能否沿用，以及團費是否含許可。 [科羅州政府許可說明](https://kororstategov.com/pdf/Fact%20Sheet_2.15.13.pdf)
- 浮潛時穿救生衣並跟隨導遊，依自身能力選擇水域。穿防磨衣遮陽，避免踩踏珊瑚；瀑布步道穿止滑鞋，若水位上升或管理方封閉就折返。 [帛琉觀光局保育規範](https://pristineparadisepalau.com/knowledge-base/?kbai_article_slug=palau-conservation-laws-visitors-should-know-2)

## 每人預算

以下是抓預算用的估算，地面費用以兩人分攤房間與包車計算。住宿等級、旅遊日期及出團人數會影響報價。

| 項目 | 每人預估 |
| --- | ---: |
| 桃園往返經濟艙 | NT$16,000–24,000 |
| 科羅住宿四晚 | USD 180–300 |
| 洛克群島快艇浮潛、獨木舟導覽 | USD 180–300 |
| 當地交通（機場接駁與陸遊包車分攤） | USD 70–130 |
| 餐飲 | USD 90–150 |
| 洛克群島許可、步道及博物館門票 | USD 70–140 |
| 當地小計 | **USD 590–1,020** |

依 USD 1＝NT$32 的試算匯率，機票加地面約 **NT$35,000–57,000／人**，旅遊保險另計。帛琉移民機關列有 USD 100 環境費，購票時確認票價是否已含，若需另付再加列。 [帛琉移民機關](https://bcbp.pw/?page_id=165)

## 訂位與出發前準備

1. **訂機票與四晚住宿。**先確認第 1 天抵達、第 5 天出發，並把航班號與抵達時間交給飯店安排雙程接駁。
2. **訂海上活動與陸遊。**優先鎖定第 2 天船團，再訂第 3 天包車與第 4 天獨木舟。付款前確認海況取消與改期條款、接送、餐飲、裝備與門票。若需要中文導覽，訂位時確認。
3. **準備入境文件。**以台灣護照為例，出發前核對護照至少還有六個月效期及持有回程機票，並在起飛前 72 小時內依官方指示填寫 Palau Entry Form，保存完成後的 QR Code。其他護照請查對應規定。 [帛琉入境規定](https://bcbp.pw/?page_id=165) · [Palau Entry Form](https://www.palautravel.pw/)
4. **整理裝備。**帶防磨衣、防水袋、止滑鞋、可重複使用的水瓶、美元零鈔，並核對旅遊保險是否涵蓋浮潛與獨木舟。
